Because of the Maltese Fiction Frequency List's MS-NC-No ReD licence I cannot fully upload the Beta version of the Anki deck, but you can however quite easily make one yourself with this script, just download the txt file from the Clarin project page (https://www.clarin.eu/resource-families/maltese-fiction-wordlist).

The deck is obviously unfinished, but the Wiktionary links are automatically generated so you can manually add the relevant information while learning. Also feel free to exclude the english-malti dictionary in the code if you don't find it usefull!

To make the Anki Deck from the resulting malt_freq.csv file, click and drag it into the Anki application and choose "Comma" as the "Field separator".

I added a bare-bones html document containing the Anki Card-Template I developed, but feel free to make the cards however you want.
